# Sarı Tenis Topu Nesne Takibi

## Proje Açıklaması
Bu projede video segmentasyonu ve karar destek sistemi kullanılarak sarı tenis topunun renk tabanlı nesne takibi gerçekleştirilmiştir.

## Kullanılan Teknolojiler
- Python
- OpenCV
- NumPy
- Matplotlib

## Proje Adımları
1. Video ön işleme
2. HSV dönüşümü
3. Renk tabanlı segmentasyon
4. Nesne tespiti
5. Nesne takibi
6. Karar destek sistemi

## Çıktılar
- Segmentasyon görüntüleri
- Nesne takip sonuçları
- Performans değerlendirmeleri
